Create a Login with Amazon (LWA) security profile once, using the Amazon developer account that owns your personal skill.

  1. Save your public audio URL on the previous step so the callback URL below is correct.
  2. Open the Login with Amazon developer console ↗. Choose Create a New Security Profile, enter a name (for example Music Assistant), a description and the required privacy notice URL, then save.
  3. Open the profile’s gear menu → Web Settings → Edit. Add the exact callback below to Allowed Return URLs, then save. Use Allowed Return URLs, rather than Allowed Origins or the Home Assistant ingress address.
  4. Copy the profile’s Client ID and Client Secret into the fields below. Select Save Amazon settings, then Connect.
