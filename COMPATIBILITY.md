# Compatibility

The device and region list below records historical upstream testing. For the maintained Home Assistant add-on, stable 1.2.0 has automated ARM64/AMD64 container validation and maintainer-confirmed playback on a real Alexa device with NPM on 3 October 2026. The device model and a complete optional-feature test matrix were not supplied, so this does not validate every entry below. APL remains optional and disabled by default. See the [deployment guide](README.md#2-home-assistant-add-on).

## Supported Languages & Regions (tested)

- en-US, US
- en-US, PT

## Supported Devices (tested)

### Non-APL devices: 
- **Echo (Gen 1)**
- **Echo (Gen 3)**

- **Echo Dot (Gen 2)**
- **Echo Dot (Gen 3)**

## Currently Unsupported Devices (tested)
